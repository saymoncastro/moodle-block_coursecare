# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.7.x (beta) | Yes |
| Earlier 0.x | No (upgrade to the latest release) |

## Reporting a vulnerability

Please report security problems **privately**, not in public issues:

- GitHub: use **Security > Report a vulnerability** on
  https://github.com/saymoncastro/moodle-block_coursecare (private vulnerability reporting).

Include the affected version, Moodle version, steps to reproduce and the impact. Do not include personal
data from real users or courses. You will receive an acknowledgement, and fixes are released as a new
version with a note in CHANGES.md once users can update.

CourseCare stores no personal data and has no write actions in its interface; see
[docs/privacy.md](docs/privacy.md).
