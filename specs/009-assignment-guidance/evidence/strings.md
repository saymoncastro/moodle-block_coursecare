# Strings novas e tipo de texto (Feature 009, T010, T014, FR-021)

Tipos da Feature 008. Nenhuma string sugere valor, julga a configuração ou promete economia, desempenho ou
sustentabilidade; os nomes de seções e campos do Moodle entram como parâmetros, vindos das strings do
próprio Moodle (`assign`, `assignsubmission_file`, `settings`), no idioma e na versão do site.

| Chave | Tipo |
| --- | --- |
| `guidance:title`, `guidance:stepstitle`, `guidance:questionstitle`, `suggestion:attempts:review` | Rótulo de interface |
| `guidance:meaning` | Fato observado (o que o potencial é e não é) |
| `guidance:implication_wide`, `guidance:implication_close` | Possibilidade (duas direções) |
| `guidance:source_default`, `guidance:source_above` | Fato observado (origem do limite) |
| `guidance:attempts_unlimited`, `guidance:attempts_untilpass` | Fato observado (comportamento do Moodle) |
| `guidance:step_open`, `guidance:step_files`, `guidance:step_attempts`, `guidance:step_groups`, `guidance:step_save`, `suggestion:attempts:steps` | Orientação prática |
| `guidance:settingslink`, `guidance:link` | Orientação prática (navegação) |
| `guidance:question_type`, `guidance:question_count`, `guidance:question_size` | Possibilidade (reflexão) |
| `guidance:novalue` | Possibilidade (autonomia: não há valor certo) |
| `suggestion:attempts:title` | Possibilidade |
| `suggestion:attempts:observed` | Fato observado (na análise) |
| `suggestion:attempts:why` | Possibilidade (direção aprovada) |
| `suggestion:attempts:todo` | Orientação prática, opcional ("se quiser") |
| `suggestion:attempts:changed` | Fato observado, datado (divergência) |
| `state:idea_message_attempts`, `state:idea_message_both` | Fato observado (existe sugestão) |
| `state:idea_action_plural` | Orientação prática (navegação) |
| `privacy:metadata` (atualizada) | Declaração de privacidade |

A redação em inglês do cartão segue a direção aprovada pelo proprietário do produto (FR-010b); revisão de
tom das demais strings novas: pendente (grupo B), junto da avaliação das capturas.
