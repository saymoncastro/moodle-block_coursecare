# Contract: orientação e sugestão de tarefas (Feature 009)

## Orientação informativa (seção "Potencial das tarefas", aba "Em detalhes")

Em cada tarefa com estado `potential` ou `unlimited`, depois do resultado da 005, um `<details>` fechado
"How to read and review these settings" / "Como entender e revisar estas configurações":

1. **Configuração atual** — as frases da 005 (sem recálculo).
2. **O que significa** — "These limits are a ceiling set by the settings, not the space used." / "Esses
   limites são um teto das configurações, não o espaço usado."
3. **Implicações possíveis** — duas frases, uma em cada direção (limites amplos podem ser exatamente o que
   a atividade pede; limites próximos do que a entrega exige podem ajudar a indicar o formato esperado).
4. **Origem do limite** — padrão do site / sala / site / servidor, quando for o caso (FR-003).
5. **Tentativas** — ilimitadas ou "até passar", quando for o caso (FR-004).
6. **Como revisar no Moodle** — passos com as strings do Moodle: "Submission settings" › "Allowed
   attempts", "Grant attempts"; "Submission types" › "File submissions", "Maximum number of uploaded files",
   "Maximum submission size"; "Students submit in groups" quando aplicável.
7. **Link** "Open the settings of this assignment" / "Abrir as configurações desta tarefa" (só com
   permissão de editar).
8. **Perguntas para refletir** — sem valores.
